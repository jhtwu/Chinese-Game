## 1. 遊戲概念

### 1.1 核心理念
結合經典俄羅斯方塊的遊戲性與中文詞語學習，創造一個既有趣又具教育意義的學習遊戲。

### 1.2 目標玩家
- 中文學習者（HSK 1-6 級別）
- 年齡層：12 歲以上
- 想要以遊戲方式增進中文詞彙的學習者

### 1.3 核心玩法
**詞語配對消除系統**：玩家操控帶有中文單字的方塊，將正確的字組合成詞語後即可消除並得分。

---

## 2. 遊戲機制

### 2.1 基礎機制（沿用俄羅斯方塊）

#### 方塊系統
- **形狀**：使用經典俄羅斯方塊的 7 種形狀（I, O, T, S, Z, J, L）
- **方塊單位**：每個小方格顯示一個中文字
- **下落速度**：隨時間/關卡遞增
- **控制**：
  - ← → 左右移動
  - ↓ 加速下落
  - 空格鍵 快速下落
  - ↑ 旋轉方塊

#### 遊戲場地
- **尺寸**：10 格寬 × 20 格高（經典尺寸）
- **預覽**：顯示下一個方塊（包含其中的文字）

### 2.2 創新機制（中文詞語配對）

#### 詞語匹配規則

**基礎配對（兩字詞）**
```
範例：
  學 + 習 → "學習" ✓ 消除 (+10分)
  學 + 校 → "學校" ✓ 消除 (+10分)
  學 + 生 → "學生" ✓ 消除 (+10分)
  學 + 車 → 無效組合 ✗ 不消除
```

**進階配對（三字詞、四字詞）**
```
範例：
  圖 + 書 + 館 → "圖書館" ✓ 消除 (+20分)
  一 + 心 + 一 + 意 → "一心一意" ✓ 消除 (+30分)
```

#### 配對方向
詞語可以在以下方向形成：
- **橫向**：從左到右 ←→
- **縱向**：從上到下 ↑↓
- **不支持對角線**（保持簡單）

#### 消除機制
1. **即時檢測**：方塊固定後，系統立即檢測所有可能的詞語
2. **多重消除**：同時形成多個詞語可獲得連擊獎勵
3. **部分消除**：只消除形成詞語的方塊，其他方塊保留
4. **重力下落**：消除後，上方方塊自動下落填補空位

**消除動畫順序：**
```
1. 檢測詞語 (100ms)
2. 高亮顯示詞語 (300ms)
3. 播放詞語讀音 (語音)
4. 顯示詞義提示 (500ms)
5. 消除動畫 (400ms)
6. 方塊下落 (300ms)
```

## 3. 計分系統

### 3.1 基礎分數

| 詞語長度 | 基礎分數 | 範例 |
|----------|----------|------|
| 兩字詞   | 10 分    | 學習、漢字 |
| 三字詞   | 20 分    | 圖書館、咖啡館 |
| 四字詞   | 40 分    | 一心一意、風和日麗 |
| 成語特別獎勵 | +20 分 | 四字成語額外獎勵 |

### 3.2 連擊系統

```
連擊倍率：
1 詞 → 1.0x
2 詞 → 1.5x
3 詞 → 2.0x
4+ 詞 → 2.5x
```

**計算範例：**
```
同時消除 3 個兩字詞：
(10 + 10 + 10) × 2.0 = 60 分
```

### 3.3 速度獎勵
- 快速配對（3 秒內完成）：+5 分
- 完美配對（5 個詞連擊）：+50 分

### 3.4 特殊獎勵
- **主題配對**：同主題詞語（如：學習、學校、學生） +15 分
- **稀有詞**：HSK 高級詞彙 +10 分

## 4. 難度設計

### 4.1 難度級別

| 級別 | HSK 對應 | 詞庫大小 | 下落速度 | 字符重複率 |
|------|----------|----------|----------|------------|
| 初級 | HSK 1-2 | ~300 詞 | 慢（1格/秒） | 高（60%） |
| 中級 | HSK 3-4 | ~600 詞 | 中（1.5格/秒）| 中（40%） |
| 高級 | HSK 5-6 | ~1200 詞 | 快（2格/秒） | 低（20%） |

### 4.2 漸進難度
- **每 5 關**：速度 +10%
- **每 10 關**：引入更高級別詞彙
- **第 20 關後**：混合所有級別詞彙

## 5. 遊戲模式

### 5.1 經典模式（Classic Mode）
- 無限遊戲，直到方塊堆滿頂部
- 目標：獲得最高分
- 支持排行榜

### 5.2 限時模式（Time Attack）
- 3 分鐘限時挑戰
- 目標：在時間內獲得最高分
- 每消除一個詞 +2 秒時間獎勵

### 5.3 學習模式（Learning Mode）
- 無時間壓力，速度固定
- 提供更多提示和解釋
- 顯示詞義和例句
- 不計入排行榜

### 5.4 主題挑戰（Theme Challenge）
- 特定主題詞彙（如：食物、動物、旅遊）
- 每日更新不同主題
- 完成可解鎖成就

### 5.5 多人對戰（未來版本）
- 雙人競技
- 消除詞語可發送干擾給對手
- 即時對戰模式

## 6. 詞庫設計

### 6.1 詞庫來源
- 基於 **HSK 官方詞表**
- 補充常用口語詞彙
- 分級管理，確保學習曲線

### 6.2 詞庫結構
```json
{
  "word": "學習",
  "characters": ["學", "習"],
  "pinyin": "xué xí",
  "hsk_level": 1,
  "category": "education",
  "definition": "to study, to learn",
  "example": "我每天學習中文。",
  "frequency": 0.85
}
```

### 6.3 字符分佈策略
**智能字符生成算法：**
1. **高頻字優先**：常用字如「的、一、是」出現率更高
2. **可組合性**：優先選擇能組成多個詞的字
3. **難度適配**：根據玩家級別調整字符難度
4. **避免孤字**：減少無法組詞的字出現

**範例分佈（初級）：**
```
學 (30%) - 可組成：學習、學校、學生
生 (25%) - 可組成：學生、生活、生日
活 (20%) - 可組成：生活、活動
...
```

## 8. 教學與輔助系統

### 8.1 新手教學
**首次遊玩時觸發互動式教學：**
1. **第 1 步**：學習基礎控制（移動、旋轉）
2. **第 2 步**：完成第一個兩字詞配對
3. **第 3 步**：了解連擊機制
4. **第 4 步**：體驗提示系統

### 8.2 提示系統

**三種提示等級：**
1. **輕度提示**（免費）：高亮可組詞的字（不顯示具體詞語）
2. **中度提示**（-5分）：顯示 1 個可能的詞語
3. **重度提示**（-10分）：顯示所有可能的詞語 + 詞義

**智能提示觸發：**
- 玩家 30 秒無動作
- 方塊堆積超過 15 層
- 玩家主動請求

### 8.3 學習記錄

**自動記錄玩家的學習數據：**
- 已學詞彙列表
- 每個詞的出現次數
- 配對成功率
- 薄弱詞彙標記
- 學習時長統計

**生成學習報告：**
```
本週學習報告：
✅ 新學詞彙：25 個
✅ 複習詞彙：50 個
⭐ 掌握程度：HSK 2 (85%)
📈 進步最快：食物類詞彙
⚠️ 需加強：方位詞
```
